## Architecture

This is a **Next.js 16 App Router** application for Crain Painting Contractors. It has three main user-facing features:

### 1. Paint Visualizer (main flow, `/`)
A 3-step wizard: pick colors -> upload photo -> choose surface -> view AI-generated results. Uses **Nano Banana Pro** (`nano-banana-pro-preview`) with fallbacks to **Nano Banana 2** (`gemini-3.1-flash-image-preview`) and **Nano Banana** (`gemini-2.5-flash-image`) to repaint specific surfaces in user photos. Each surface type has a carefully crafted prompt template in `src/lib/prompt.ts` that tells the AI exactly what to paint and what to leave alone. Results are stored in Vercel Blob.

### 2. Expert Color Consultation (`/consultation`, `/expert`)
Paid consultation flow with a style quiz (room type, mood, AI-suggested colors via `/api/consultation/quiz`), then a form with photo upload, window direction, address (geocoded for sun position analysis), and Stripe checkout. Reports are generated by **Claude** (`src/lib/claude.ts`) with color recommendations, time-of-day lighting analysis, and surface prep guides.

### 3. Admin Dashboard (`/admin/*`)
Password-protected (iron-session middleware) client/proposal management. Clients have proposals containing visualization results (before/after images with color metadata). Soft-delete for proposals.

### Key Data Flow: Visualization Pipeline
1. Client compresses image (<4MB) and sends FormData to `POST /api/visualize`
2. Server uploads original to Vercel Blob, builds surface-specific prompt (`src/lib/prompt.ts`)
3. Sends image + prompt to Gemini API (`src/lib/gemini.ts`)
4. Uploads result image to Vercel Blob, creates share JSON, returns URLs
5. Rate limited: 20 requests/IP/hour (in-memory, `src/lib/rate-limit.ts`)

### Color Catalogs
~3,500 Benjamin Moore + ~1,800 Sherwin-Williams colors stored as JSON in `src/data/`. Loaded and normalized in `src/lib/colors.ts`. The `BMColor` type (in `src/types/colors.ts`) is used throughout with fields: number, name, family, hex (no # prefix), brand.

### Color Shift Algorithm
`src/lib/color-shift.ts` calculates how paint appears at morning/afternoon/evening based on window direction. Applies RGB temperature shifts with direction-based modifiers (north = cooler, south = warmer).

### Sun Analysis
`src/lib/sun-analysis.ts` uses SunCalc to compute sun positions for a lat/lng. Used in consultation reports to analyze how natural light affects color throughout the day.

## Tech Stack

- **Next.js 16** with React Compiler enabled, App Router, server components
- **Tailwind CSS v4** + **shadcn/ui** (new-york style, lucide icons)
- **Fonts**: Open Sans (body, `--font-body`), Merriweather Sans (headings, `--font-heading`)
- **Brand colors**: Primary `#27CCC0` (teal), Accent `#F6653C` (orange), Background `#FAFAFA`
- **Database**: Vercel Postgres (3 tables: clients, proposals, proposal_results)
- **Storage**: Vercel Blob (originals/, results/, shares/)
- **Payments**: Stripe (checkout sessions for consultation packages: $49/$149/$399)
- **AI**: Nano Banana Pro / Nano Banana 2 / Nano Banana (image generation), Claude Sonnet (report generation)
- **Email**: Resend
- **Auth**: iron-session (admin only, cookie-based, 8hr expiry)
- **Path aliases**: `@/` maps to `src/`

## Conventions

- All API routes are in `src/app/api/` using Next.js Route Handlers
- UI components live in `src/components/ui/` (shadcn), feature components in `src/components/<feature>/`
- Types are in `src/types/`, utilities in `src/lib/`
- Consultation types (`src/types/consultation.ts`) define packages, room types, moods, window directions, and all order/report structures
- Proposal types (`src/types/proposals.ts`) define client/proposal CRUD shapes
- `src/middleware.ts` protects all `/admin/*` routes except `/admin/login`
- Color hex values are stored WITHOUT the `#` prefix throughout the codebase
